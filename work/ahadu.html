Ahadu — Restaurant & Cafe Website

A demo site for an all-day restaurant and café in Addis Ababa: a dark home page, an easy-to-browse menu, table reservations and an admin area.

Next.js Postgres Drizzle ORM Tailwind

Menu With Ingredient Details

The menu is grouped by meal, with tags for vegetarian, vegan, spicy and gluten-free dishes. Each dish opens an ingredient breakdown, and phones show two items per row.

Reservations

A booking form (party size, date, email) checks how many seats are left in each 30-minute slot. A hidden spam field and rate limiting keep bots out. Bookings are saved to Postgres.

Admin panel (demo mode)

A password-protected admin lets you add, edit and delete menu items and gallery images, and read the reservations. The menu and gallery edits are kept in your own browser on purpose, so anyone can try the admin without changing the real menu. Reservations are the part that is saved for real, shown read-only.

Design

An animated splash, a dark home page and a lighter menu for easy reading, plus a preview image and per-page metadata. I can re-skin it for a client's own restaurant.
